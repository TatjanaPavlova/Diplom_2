## Дипломный проект. Часть 2: автоматизация тестов для Stellar Burgers
<hr>

## Студентка: Татьяна Павлова, 28 когорта

Тестируем API, покрывая ключевой функционал:  
- Создание пользователя  
- Логин пользователя 
- Создание заказа

## Стек
- Python 3.10+  
- Pytest  
- Allure для отчётов  
- Requests для работы с API

## Структура проекта
- `tests/` — тесты для ручек API  
- `data.py` — константы и тестовые данные  
- `generators.py` — генерация случайных email, паролей и имён  
- `conftest.py` — фикстуры для создания пользователей и их удаления  
- `allure-report/` — сгенерированный HTML-отчёт Allure

## Покрытие тестами
- Пользователи: создание, логин, ошибки при дублировании и отсутствии обязательных полей
- Заказы: создание с авторизацией, без авторизации, с ингредиентами, без ингредиентов, с неверными хешами
- Все тестовые данные создаются перед тестом и удаляются после него

## Создание и активация виртуального окружения
```bash
python -m venv venv
source venv/bin/activate   # для Linux/Mac
venv\Scripts\activate      # для Windows
```

## Запуск тестов
1. Установить зависимости:
```bash
pip install -r requirements.txt
```

2. Запустить тесты:
```bash
pytest --alluredir=allure_results
```

3. Сгенерировать Allure-отчёт:
```bash
allure serve allure_results
```
